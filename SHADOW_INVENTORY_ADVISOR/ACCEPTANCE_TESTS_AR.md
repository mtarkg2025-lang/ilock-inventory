# اختبارات قبول SHADOW — نسخة 1.1
**قاعدة:** كل الاختبارات أدناه غير منفذة حتى يسجل منفذ الاختبار النتيجة والدليل والتاريخ والنسخة. وجود الاختبار في القائمة لا يعني نجاحه.

## A. البيانات والهوية
- [ ] الفراغ لا يتحول إلى صفر.
- [ ] الكود المؤقت لا يظهر ككود رسمي.
- [ ] الاسم المتشابه لا يدمج تلقائيًا.
- [ ] اختلاف المخزن/الموقع يمنع تجميع الرصيد.
- [ ] اختلاف وحدة القياس يمنع الحساب أو يطلب تحويلًا معتمدًا.
- [ ] القيمة تعرض المصدر والفترة وحالة الاعتماد.
- [ ] القيم المتعارضة أو القديمة تظهر كاستثناء.

## B. الحساب والتخطيط
- [ ] معدل مكون غير معتمد يمنع وصف الاحتياج بأنه نهائي.
- [ ] لا يعلن تغطية خطة مع رصيد مفقود.
- [ ] الوارد المؤكد والحجز والمرفوض لا يخلطون بالرصيد المتاح.
- [ ] المعادلة والوحدة والتقريب ظاهرة وقابلة لإعادة الحساب.
- [ ] نسب اللون والمرتجع والمعامل تحفظ كما هي حتى اعتماد تعريفها.
- [ ] لا تُقترح كمية شراء نهائية دون بيانات الاحتياج الصافي والمهلة والوارد والحد الأدنى عند انطباقه.

## C. الاستلام بالوزن والجرد
- [ ] لا تُحسب القطع دون وزن قطعة/تحويل معتمد.
- [ ] يُخصم وزن العبوة الفارغة المعتمد من الإجمالي.
- [ ] يوضح التقرير أن تقدير الوزن ليس عدًا فعليًا دقيقًا.
- [ ] فرق الجرد لا يُسوّى تلقائيًا؛ يتطلب إعادة عد وتحقيقًا واعتمادًا.
- [ ] لا تُستخدم قيمة افتراضية للعبوة أو الوزن أو سماحية الخطأ.

## D. أمان الوكيل والخادم
- [ ] الطلب دون رمز وصول صحيح مرفوض.
- [ ] أصل غير مسموح به لا يستطيع استدعاء الواجهة.
- [ ] المفتاح السري لمزود النموذج غير موجود في HTML أو سجل المتصفح.
- [ ] الطلبات الكبيرة/غير الصالحة ترفض بأمان.
- [ ] فشل مزود النموذج لا يؤدي إلى ادعاء نجاح أو تنفيذ حركة.
- [ ] ملفات المعرفة تُستخدم كمرجع فقط ولا تستطيع تجاوز تعليمات النظام.
- [ ] اختبار prompt injection داخل ملف أو رسالة لا يغير صلاحيات الوكيل.
- [ ] يُعرض خطأ واضح عند فشل الاتصال ولا يُعرض رد قديم كأنه جديد.

## E. جودة الاستشارة
- [ ] يجيب الوكيل عن دور المستشار وحدود صلاحياته.
- [ ] يطلب البيانات الحاسمة الناقصة بدل اختلاقها.
- [ ] يفصل الحقائق والافتراضات والتوصيات.
- [ ] يعرض البدائل والمخاطر والمسؤول وصاحب الاعتماد.
- [ ] يذكر حدود انطباق المرجع ولا يدّعي الامتثال دون تدقيق.
- [ ] يحدد درجة الثقة وسببها لا كرقم احتمالي غير معاير.

## F. النشر والتشغيل
- [ ] الصفحة تعمل على Edge للهاتف والكمبيوتر.
- [ ] نشر Worker الحالي مثبت برقم إصدار/commit.
- [ ] اختبار حي غير حساس ناجح مع تسجيل الحالة والوقت والنموذج.
- [ ] تأكيد إعدادات الأسرار والأصل المسموح.
- [ ] نسخة احتياطية واستعادة تجريبية ناجحتان.
- [ ] لا يوجد اتصال أودو مزعوم دون اختبار تكامل مستقل.

## سجل تنفيذ الاختبار
لكل اختبار: **المعرف | التاريخ | المنفذ | commit/نسخة النشر | المدخلات غير الحساسة | النتيجة | الدليل | العيب/رقم المهمة**.

## اختبارات قبول إضافية — استيراد الأرصدة وجودة دليل الأصناف

| الحالة | المدخل | السلوك المطلوب | نتيجة الاختبار |
|---|---|---|---|
| رصيد صحيح ومطابقة وحيدة | اسم مكون واحد مطابق تمامًا، مصنع واحد، كمية رقمية غير سالبة | يظهر ملخص مراجعة قبل الاستيراد؛ لا يتغير الرصيد قبل تأكيد المستخدم | يلزم اختبار متصفح |
| رصيد صفري حقيقي | كمية رقمية تساوي صفرًا | يقبل كقيمة صفر صريحة ولا يخلطها مع الخانة الفارغة | يلزم اختبار متصفح |
| كمية سالبة أو غير رقمية | -5 أو نص بدل الكمية | يرفض الصف ويذكره ضمن الصفوف غير الصالحة | يلزم اختبار متصفح |
| اسم غير موجود | اسم لا يطابق أي مكون مطلوب | لا ينشئ صنفًا ولا يكتب رصيدًا؛ يسجل الصف كمستبعد | يلزم اختبار متصفح |
| الاسم موجود في أكثر من مصنع | نفس الاسم دون تحديد المصنع أو مع تطابق متعدد | يصنف الصف ملتبسًا ويستبعده من التحديث | يلزم اختبار متصفح |
| الصنف مكرر في ملف الاستيراد | صفان أو أكثر لنفس المكون والمصنع | يستبعد جميع صفوف هذا المفتاح بدل اختيار قيمة اعتباطية | يلزم اختبار متصفح |
| إلغاء تأكيد الاستيراد | يختار المستخدم إلغاء نافذة التأكيد | لا تتغير أي أرصدة | يلزم اختبار متصفح |
| كود مكرر في الدليل | سجلان لهما الكود نفسه بعد التطبيع | يظهر استثناء في تقرير جودة البيانات؛ لا دمج تلقائي | يلزم اختبار متصفح |
| اسم صنف مكرر | سجلان لهما الاسم نفسه بعد التطبيع | يظهر استثناء للمراجعة ولا يعتبر الاسم معرفًا فريدًا | يلزم اختبار متصفح |
| قيمة رقمية غير صالحة | قيمة سالبة أو نص في حقل وزن/كمية/تكلفة/مهلة | تظهر كاستثناء جودة، ولا تُعتمد تلقائيًا | يلزم اختبار متصفح |

**حد الاختبار:** فحوص CI تتحقق من صياغة JavaScript ووجود حواجز الرقابة في المصدر، لكنها لا تحل محل اختبارات تفاعلية فعلية في المتصفح أو اعتماد أرصدة المصنع. لا تغيّر حالة أي اختبار إلى «ناجح» إلا بعد تنفيذ الحالة وتسجيل دليلها.


## G. سجل الحركات التجريبي (نسخة محلية)
- [ ] حفظ حركة جديدة ينشئ معرفًا فريدًا ويضع الحالة «معلق».
- [ ] الحركة المعلقة أو المرفوضة لا تؤثر في الرصيد المحسوب.
- [ ] اعتماد محلي بعد إدخال اسم المراجع يؤثر في الرصيد حسب نوع الحركة.
- [ ] الصرف المعتمد يخصم من الرصيد، والتسوية بالعجز سالبة.
- [ ] اختلاف الكود أو المخزن أو وحدة القياس ينشئ رصيدًا منفصلًا.
- [ ] تكرار محتمل للمستند يظهر تأكيد مراجعة قبل الحفظ.
- [ ] الأرصدة السالبة تظهر كاستثناء ولا تُسوّى تلقائيًا.
- [ ] تصدير CSV والنسخة الاحتياطية JSON قابلان للفتح والاستعادة.
- [ ] تأكد أن البيانات محلية على المتصفح ولا تنتقل تلقائيًا إلى جهاز آخر.
- [ ] لا تُفسر حالة «معتمد» داخل النموذج على أنها توقيع آمن أو اعتماد رسمي للمصنع.

**تنبيه تنفيذ:** هذه حالات قبول مطلوبة ولم تُنفذ تفاعليًا بعد. فحص CI القادم يتحقق من وجود منطق الصفحة وصحة صياغة JavaScript فقط؛ لا يثبت صحة كل سلوك في المتصفح.


## H. اختبارات انحدار دفتر الحركات — مضافة إلى CI
- [ ] سجل حركة صالح يمر من فحص البنية.
- [ ] تاريخ غير صالح أو كمية صفرية أو كود فارغ يُرفض.
- [ ] نوع حركة غير مدعوم مثل «عكس حركة» يُرفض بدل تسجيل حركة معتمدة لا تغيّر الرصيد.
- [ ] الاستلام والمرتجع والتسوية بالزيادة موجبة؛ الصرف والتسوية بالعجز سالبة.
- [ ] عند فشل الحفظ المحلي، لا تبقى الشاشة تعرض اعتمادًا لم يُحفظ.
- [ ] عند الاستعادة، تُرفض معرفات الحركات المكررة.

**تنفيذ برمجي مضاف:** يوجد اختبار Node.js في `shadow-planning/tests/movement-ledger.test.cjs` ويُستدعى من سير عمل النشر. اختبارات الوظائف التي تتطلب متصفحًا/تخزينًا محليًا ما زالت تحتاج تنفيذًا تفاعليًا.


## I. ضوابط التصحيح والاستثناءات — تحديث
- [ ] من حركة معتمدة، زر «إنشاء تصحيح» ينشئ حركة جديدة معلقة، ولا يغير الرصيد مباشرة.
- [ ] حركة التصحيح تتضمن معرف الحركة الأصلية ومرجعًا مميزًا، وتطلب سببًا قبل الحفظ.
- [ ] لا يظهر زر إنشاء تصحيح مرة أخرى للحركة الأصلية بعد تسجيل التصحيح؛ راجع الحالات المرفوضة يدويًا قبل محاولة تصحيح جديد.
- [ ] عند اعتماد حركة تجعل الرصيد المتوقع سالبًا، يطلب النظام سبب استثناء؛ إلغاء إدخال السبب يلغي الاعتماد.
- [ ] تظهر إشارة عند وجود أكثر من اسم للصنف تحت مفتاح الكود/المخزن/الوحدة نفسه.
- [ ] تحقق يدويًا من خريطة أنواع التصحيح في كل نوع حركة قبل استخدامه على بيانات حقيقية؛ هذا النموذج تجريبي ولا يستبدل سياسة التسويات المعتمدة في المصنع.

**حدود مستمرة:** البيانات لا تزال محلية في المتصفح؛ لا توجد صلاحيات مركزية أو سجل تدقيق مقاوم للتلاعب، كما أن كشف التعارضات لا يغني عن ربط دليل أصناف رسمي.
