# اختبارات قبول وكيل SHADOW — النسخة الأولى
النتيجة الحالية لكل اختبار: **غير منفذ** حتى يُسجل الدليل الفعلي. هذه قائمة تحقق وليست شهادة نجاح.

## A. سلامة البيانات
- [ ] لا يتحول الحقل الفارغ إلى صفر.
- [ ] يكتشف الكود المؤقت ويمنع تقديمه باعتباره كودًا رسميًا.
- [ ] لا يدمج اسمين متشابهين دون قرار بشري.
- [ ] يعرض مصدر كل قيمة أساسية وحالة اعتمادها.
- [ ] يوقف الحساب عند اختلاف وحدات القياس أو غياب معدل أساسي.
- [ ] يحافظ على قيمة المصدر وسجل التغيير.

## B. صحة الرصيد والحركات
- [ ] الرصيد المحسوب يعتمد الرصيد الافتتاحي والحركات المعتمدة فقط.
- [ ] التحويل الداخلي لا يُحسب استهلاكًا مزدوجًا.
- [ ] الحركة المكررة تُكشف وفق معرف/مرجع موثق.
- [ ] يميز التقرير بين الرصيد الدفتري والعد الفعلي والفرق.
- [ ] لا ينشئ الوكيل حركة أو تسوية تلقائيًا.

## C. الاستلام بالوزن
- [ ] اختبار الوزن الصافي: إجمالي العبوات ناقص مجموع وزن الفارغ.
- [ ] اختبار تحويل الكيلو جرام والجرام في حساب عدد القطع.
- [ ] رفض وزن قطعة يساوي صفرًا أو قيمة سالبة.
- [ ] عرض خطأ إذا تجاوز وزن الفارغ الإجمالي.
- [ ] عدم اعتماد العدد التقديري بدل العد الفعلي دون إجراء معتمد.
- [ ] عدم وجود وزن افتراضي أو حد تسامح مخترع.
- [ ] تصدير واستيراد CSV مع الحفاظ على أسماء الأعمدة العربية قدر الإمكان.

## D. تخطيط احتياجات المكونات
- [ ] يربط خطة معتمدة بمعدل معتمد ووحدة متسقة.
- [ ] يوضح الاحتياج الإجمالي والصافي ومكونات الحساب.
- [ ] يستبعد الحجوزات أو الطلبات الواردة فقط وفق تعريف معتمد.
- [ ] يضع «غير محسوم» عند وجود مكون غير مطابق.
- [ ] لا يقترح شراءً نهائيًا إذا لم تتوفر بيانات المهلة/الإمداد الضرورية.
- [ ] يميز قيد المواد عن قيد الماكينات والجودة والتجميع.

## E. سلوك الاستشاري
- [ ] كل توصية تتضمن الدليل والافتراضات وحدود الثقة.
- [ ] يعرض البدائل والمخاطر والجهة صاحبة الاعتماد.
- [ ] لا يدعي تنفيذ إجراء لم ينفذه فعليًا.
- [ ] لا يدعي الامتثال لمعيار دون تدقيق نطاقه ومتطلباته.
- [ ] يميز بين المعلومة العلمية وحقيقة المصنع والاقتراح.

## F. تشغيل وحماية
- [ ] اختبار Edge والهاتف، والطباعة، والنسخ الاحتياطي والاستعادة.
- [ ] اختبار فقدان الاتصال بالمكتبات الخارجية؛ لا يضيع سجل غير مصدّر.
- [ ] مراجعة خصوصية المستودع وعدم تضمين بيانات المصنع السرية.
- [ ] توثيق نتائج الاختبار واسم المراجع والتاريخ وإصدار التطبيق.
