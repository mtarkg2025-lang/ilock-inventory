# اختبارات قبول حوكمة PMP / PMO في SHADOW

هذه الاختبارات غير منفذة حتى يسجل دليل وتاريخ ونسخة.

- [ ] لكل تغيير مشكلة وقيمة ومالك ومعيار قبول.
- [ ] النطاق وما هو خارج النطاق محددان للإصدار.
- [ ] سجل RAID يضم المخاطر والافتراضات والمشكلات والاعتماديات مع مالك واستجابة.
- [ ] تغيير الصنف أو الوحدة أو معدل المكونات له سبب واعتماد واختبارات وخطة رجوع.
- [ ] لكل بوابة G0–G6 شرط خروج ودليل وصاحب اعتماد.
- [ ] لا يُعامل نجاح CI على أنه اختبار تكامل حي أو قبول مستخدم.
- [ ] لكل KPI معادلة ووحدة ومصدر ومالك وتواتر وخط أساس معتمد.
- [ ] كل مصدر معرفة موثق بالجهة والرابط والإصدار وتاريخ الاطلاع وحقوق الاستخدام.
- [ ] لا يدّعي SHADOW اعتماد PMI أو شهادة PMP.
- [ ] لا ينفذ الوكيل قرارًا أو اعتمادًا خارج صلاحياته.
