# SHADOW Agent — محرك تخطيط ومراقبة المخزون

## فتح التطبيق
- GitHub Pages: https://mtarkg2025-lang.github.io/ilock-inventory/shadow-planning/
- المصدر: [index.html](./index.html)

## قاعدة بيانات الحقن المدمجة
- أضيفت قاعدة الأصناف المستخرجة من دليل SHADOW V23: 237 سجلًا.
- تحتوي على كود النظام، اسم الصنف، النوع، الوحدة، المخزن الافتراضي، حالة الكود، والرصيد المرجعي عند توفره.
- قاعدة البيانات محفوظة في [injection-database.json.gz.b64](./injection-database.json.gz.b64) بصيغة مضغوطة ويحمّلها التطبيق تلقائيًا.
- الأكواد التي تبدأ بـ `TMP-` أكواد داخلية مؤقتة وليست الأكواد الرسمية للمصنع.
- الأرصدة المعروضة «مرجعية للمراجعة فقط» وليست أرصدة فعلية معتمدة، ولا تدخل تلقائيًا في حساب العجز والفائض.
- مطابقة المكونات مع معدلات الإنتاج تتم بالاسم المطابق فقط؛ يجب مراجعة الأسماء التي لا تتطابق.

## الاستخدام
1. افتح قسم «قاعدة بيانات الحقن» وراجع الأصناف والأكواد.
2. حمّل ملف «معدلات انتاج المصانع شهر9.xlsx».
3. أدخل كميات التشغيل المطلوبة لكل عائلة نهائية.
4. راجع تفصيل احتياجات كل مكوّن.
5. أدخل الأرصدة الفعلية أو استورد ملف أرصدة، ثم راجع العجز والفائض.
6. صدّر CSV أو اطبع المقارنة.

## منطق الحساب
يحافظ التطبيق على أعمدة المصدر دون تعديل نسبة اللون أو نسبة المرتجع أو المعامل. احتياج المكوّن يحسب هكذا: كمية خطة المنتج × (إجمالي المصدر ÷ معدل الإنتاج).

## الحدود الحالية
- يلزم اتصال بالإنترنت لتحميل مكتبة SheetJS المستخدمة لقراءة Excel.
- خطة التشغيل والأرصدة المدخلة محفوظة محليًا في المتصفح ولا تتزامن بين الأجهزة.
- استيراد الأرصدة يعتمد على مطابقة أسماء المكونات وعناوين الأعمدة، ويجب مراجعة المطابقة يدويًا.
- المحرك للتخطيط فقط؛ لا يسجل حركات استلام أو صرف ولا يغير الرصيد الدفتري.
- يجب اختبار النتائج على خطة معروفة قبل الاعتماد التشغيلي.
