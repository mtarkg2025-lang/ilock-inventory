# SHADOW Agent — محرك تخطيط ومراقبة المخزون

## فتح التطبيق
- GitHub Pages: https://mtarkg2025-lang.github.io/ilock-inventory/shadow-planning/
- المصدر: [index.html](./index.html)

## الاستخدام
1. حمّل ملف «معدلات انتاج المصانع شهر9.xlsx».
2. أدخل كميات التشغيل المطلوبة لكل عائلة نهائية.
3. راجع تفصيل احتياجات كل مكوّن.
4. أدخل الأرصدة الفعلية أو استورد ملف أرصدة، ثم راجع العجز والفائض.
5. صدّر CSV أو اطبع المقارنة.

## منطق الحساب
يحافظ التطبيق على أعمدة المصدر دون تعديل نسبة اللون أو نسبة المرتجع أو المعامل. احتياج المكوّن يحسب هكذا: كمية خطة المنتج × (إجمالي المصدر ÷ معدل الإنتاج). هذا يستخدم إجمالي المصدر المسجل ولا يعيد تفسير المعاملات.

## الحدود الحالية
- يلزم اتصال بالإنترنت لتحميل مكتبة SheetJS المستخدمة لقراءة Excel.
- خطة التشغيل والأرصدة محفوظة محليًا في المتصفح ولا تتزامن بين الأجهزة.
- استيراد الأرصدة يعتمد على مطابقة أسماء المكونات وعناوين الأعمدة، ويجب مراجعة المطابقة يدويًا.
- المحرك للتخطيط فقط؛ لا يسجل حركات استلام أو صرف ولا يغير الرصيد الدفتري.
- يجب اختبار النتائج على خطة معروفة قبل الاعتماد التشغيلي.
