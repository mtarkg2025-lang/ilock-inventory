# SHADOW — سجل النواقص واختبارات القبول

تاريخ المراجعة: 24 أكتوبر 2026  
المستودع: https://github.com/mtarkg2025-lang/ilock-inventory  
النطاق: محرك التخطيط، دليل الأصناف، وملف معدلات سبتمبر المدمج.

## مصادر البيانات التي جرى فحصها
- `SHADOW_24_نسخة_مطورة_ورقابة_ومعادلات_مصوبة.xlsx`: دليل أصناف من 237 سجلًا، و18 حقلًا معرفًا في رأس الجدول.
- `معدلات انتاج المصانع شهر9.xlsx`: ورقة «معدلات » بها 257 صف مصدر، و10 أعمدة أصلية، و29 عائلة وفق منطق تمرير اسم العائلة إلى الصفوف التابعة.
- `الحقن(1).xlsx`: ملف تاريخي مستقل يحتوي على أوراق المنتجات والحركات والأرصدة والخام فرز تاني/هالك. لم تُدمج حركاته تلقائيًا في دليل الأصناف أو خطة سبتمبر؛ يحتاج تحليل مطابقة مستقل لتجنب خلط مصدرين أو فترات مختلفة.

## ما أُنجز
- استبدال قاعدة الأصناف المدمجة بمصدر SHADOW V24 الأحدث المتاح في المكتبة، مع الحفاظ على 18 حقلًا من المصدر.
- إضافة معدلات سبتمبر كمصدر بيانات مدمج مع الاحتفاظ بقيم الأعمدة الأصلية والخلايا الفارغة كما هي.
- إتاحة استخدام معدلات سبتمبر المدمجة مباشرة، دون الحاجة إلى إعادة رفع الملف، مع بقاء خيار رفع ملف Excel الأصلي.
- إضافة فحص آلي لحقول دليل الأصناف والأكواد المؤقتة والأسماء غير المطابقة.
- إضافة مراجع ASCM/SCOR وOracle Inventory وIAS 2 وضوابط تشغيلية قابلة للمراجعة.
- إضافة سير عمل GitHub Actions للنشر إلى GitHub Pages؛ لم يُثبت نجاح النشر المباشر بعد.

## نواقص لا يمكن استكمالها دون اعتماد المصنع

| العنصر | المطلوب لإغلاقه |
|---|---|
| الأكواد الرسمية | ملف أكواد رسمي وربط كل TMP بكود مؤكد، مع مراجعة التكرار والتشابه |
| الأرصدة الفعلية | جرد افتتاحي مؤرخ وموقع حسب كل مخزن/موقع |
| أوزان القطع والعبوات | معايرة فعلية لعدة عينات لكل صنف/لون/نسخة، واعتماد معامل الوزن |
| قائمة المكونات/BOM | اعتماد كميات المكونات لكل منتج ووحدة قياسه؛ معدلات سبتمبر ليست تلقائيًا BOM معتمدًا |
| تعريف أعمدة المعدلات | توثيق معنى «معدل الإنتاج»، «نسبة اللون»، «نسبة المرتجع»، «إجمالي»، «الإنتاج اليومي» و«معامل» |
| صيغة الاحتياج | اختبار يدوي على حالة إنتاج معتمدة قبل تثبيت معادلة الاحتياج |
| الأرصدة المتاحة للتخطيط | رصيد فعلي معتمد حسب الموقع، مع الطلبات/التحويلات المفتوحة عند توفرها |
| إعادة الطلب | تاريخ صرف/طلب موثوق، مهلة توريد معتمدة، مخزون أمان ومستوى خدمة محدد |
| تكلفة المخزون | تكلفة وحدة معتمدة وسياسة تقييم محاسبي وفق معيار IAS 2 والسياسة الداخلية |
| الربط مع الحركات | مطابقة مستقلة مع ملف `الحقن(1).xlsx` وفترة حركاته قبل استيراد أي حركة |
| تعدد المستخدمين | قاعدة بيانات مركزية، صلاحيات، سجل تغييرات، ونسخ احتياطي مركزي |
| نشر التطبيق | نجاح تشغيل GitHub Actions والتحقق من التحميل الفعلي على Edge والهاتف |

## اختبارات القبول قبل الاعتماد
1. التحقق من تحميل 237 سجلًا و18 حقلًا دون أخطاء.
2. التحقق من تحميل ملف معدلات سبتمبر المدمج وظهور 29 عائلة و236 صف مكونات صالحة.
3. مقارنة عدة صفوف عشوائية من بيانات المصدر مع الملف الأصلي بما فيها القيم العشرية والخلايا الفارغة.
4. مراجعة قائمة 41 اسم مكون غير مطابق وإغلاق كل حالة بربط معتمد أو توثيق أنها غير موجودة في دليل الأصناف.
5. اختبار احتياج منتج واحد يدويًا باستخدام مثال معتمد من الإنتاج، وعدم اعتماد الصيغة قبل مطابقة النتيجة.
6. اختبار الرصيد المفقود والصفر والأقل من الاحتياج والأعلى منه.
7. التأكد من أن الخطة لا تسجل حركات ولا تعدل الأرصدة.
8. اختبار التصدير والطباعة والنسخ الاحتياطي والاستعادة.
9. التحقق من نجاح نشر GitHub Pages فعليًا.
10. توقيع مسؤول المخزون والإنتاج/التخطيط على قبول نتائج الاختبار.
