# SHADOW — Independent Workspace (v0.2.0)

واجهة عربية Local-First لمساحات مخزون مستقلة، منشورة كواجهة ثابتة على GitHub Pages.

## ما يفعله هذا الإصدار
- مساحة عمل منفصلة لكل مستخدم داخل المتصفح.
- دليل أصناف مع نوع التعبئة وطريقة احتساب الكمية.
- تسجيل استلام وصرف وتسوية زيادة مع منع الصرف فوق الرصيد.
- مشاركة اختيارية عبر ملف JSON للأصناف والحركات ولقطة رصيد مرجعية.
- كشف تعارضات الأكواد ومنع استيراد السجلات المكررة بالمعرف.
- نسخة احتياطية واستعادة إلى مساحة مستقلة.
- PWA قابلة للتثبيت وتخزين ملفات التطبيق مؤقتًا للعمل بعد أول فتح.

## حدود مهمة
- البيانات محفوظة محليًا في المتصفح؛ لا توجد مزامنة تلقائية بين الأجهزة.
- المساحات داخل نفس المتصفح ليست حدودًا أمنية أو حسابات مصادقة.
- GitHub Pages يستضيف ملفات الواجهة فقط، ولا يخزن بيانات المستخدمين التشغيلية.
- لتمكين مزامنة اختيارية تلقائية لاحقًا نحتاج Backend/Auth/Database بسياسات فصل بيانات واختبارات تزامن.
- هذا الإصدار تجريبي وليس سجلًا رسميًا معتمدًا للمصنع.

## التشغيل
افتح رابط GitHub Pages للمجلد `/shadow-independent/` من الهاتف أو الكمبيوتر. يمكن لكل مستخدم إنشاء مساحة عمله. لمشاركة بيانات، أنشئ ملف مشاركة من جهاز المصدر ثم استورده على جهاز المستلم.

لا ترفع ملفات بيانات المصنع أو النسخ الاحتياطية إلى مستودع GitHub العام.
