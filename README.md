## وظيفة SHADOW
1. تدقيق دليل الأصناف وحالات الأكواد.
2. إدخال ومراجعة خطط المنتجات النهائية.
3. تحويل الخطة إلى احتياجات مكونات وفق معدلات معتمدة.
4. مقارنة الاحتياج بالأرصدة الفعلية المعتمدة.
5. إظهار العجز والفائض والاستثناءات مع توضيح سبب النتيجة.
6. دعم رقابة الاستلام بالوزن والجرد والحركات.
7. تفسير النتائج وفق قواعد المعرفة والمراجع، مع إظهار النواقص والافتراضات والثقة.
8. اقتراح إجراءات قابلة للقياس، مع إبقاء الاعتماد والتنفيذ النهائي بيد المسؤول المخول.

## قواعد لا يجوز تجاوزها
- لا تُستخدم الأكواد المؤقتة TMP-* باعتبارها أكواد المصنع الرسمية.
- لا تُعامل الأرصدة المرجعية كأرصدة فعلية معتمدة.
- لا تُخترع أوزان أو تكاليف أو أرصدة أو معدلات إنتاج أو حدود إعادة طلب.
- التخطيط منفصل عن التنفيذ: لا ينشئ SHADOW استلامًا أو صرفًا ولا يعدّل الرصيد الدفتري تلقائيًا.
- عند عدم اكتمال البيانات، تُعرض النتيجة باعتبارها غير محسومة بدل اختلاق قيمة.
- لا ترفع بيانات تشغيل المصنع الحساسة إلى مستودع عام؛ راجع إعدادات الخصوصية قبل إضافة ملفات حقيقية.
- وجود قاعدة معرفة لا يعني أن الوكيل الذكي متصل بها أو يقرأها تلقائيًا؛ يلزم دمج تقني واختبارات قبل وصفه بأنه يعمل كوكيل متكامل.

## الحالة الحالية المعروفة
بحسب سجل التدقيق الموثق في مجلد shadow-planning:
- دليل SHADOW V24 يحتوي على 237 سجلًا، وأكوادها الحالية مؤقتة وتحتاج مطابقة مع المصدر الرسمي.
- بيانات سبتمبر تشمل 29 عائلة و236 صف مكونات صالحًا حسابيًا وفق المنطق الحالي.
- توجد 41 تسمية مكون فريدة غير مطابقة في الفحص الأولي.
- تعريف معادلة المعدلات وبعض الحقول التشغيلية ما زال يحتاج اعتمادًا.
- البيانات لا تتصل مباشرة بأودو؛ التخطيط المحلي في المتصفح ليس قاعدة مركزية مشتركة.
- أُضيفت بوابات رقابة إلزامية للاستشارات، وتوسعت اختبارات القبول لتشمل البيانات والتخطيط والوزن وأمان الوكيل والنشر.
- تم إصلاح تمرير ملفات المعرفة إلى سياق Worker وتحديث تعليمات النظام؛ يلزم نشر التعديل واختبار حي قبل اعتباره فعالًا في النسخة المستضافة.
- لم تُنفذ بعد اختبارات القبول الفعلية؛ قائمة الاختبارات ليست شهادة نجاح.
- لا يُعلن نجاح النشر أو الجاهزية إلا بعد اختبار فعلي موثق.

## مسار التنفيذ
**اعتماد مصادر البيانات → اختبار الحركات والأرصدة → الاستلام بالوزن → تخطيط المكونات → ربط المعرفة بمحرك الاستشارة → اختبار الوكيل → اعتماد الاستخدام.**

يُنفذ كل جزء على عينة معتمدة، وتوثق نتيجة الاختبار قبل توسيع الاستخدام.
