## دور محرك SHADOW
يستقبل ملف معدلات الإنتاج، ويحوّل خطة المنتجات النهائية إلى احتياجات مكونات، ثم يقارنها بالأرصدة المتاحة لإظهار العجز والفائض. التخطيط منفصل عن سجل الحركات ولا ينشئ استلامًا أو صرفًا تلقائيًا.

## تنبيه
المحرك نسخة أولية للاختبار. يجب مراجعة مطابقة المكونات والأرصدة ونتائج الحساب قبل الاعتماد. بيانات التخطيط الحالية محفوظة محليًا في المتصفح.
