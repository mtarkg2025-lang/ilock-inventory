# I LOCK ERP Inventory

نموذج عربي لإدارة المخزون في المنشآت الصناعية. تتوفر منه واجهتان متكاملتان:

* `index.html`: نموذج واجهة ويب محلية للتحليل والتشغيل.
* `google-workspace/`: مشروع Google Apps Script جاهز للربط مع Google Sheets وتشغيله من Sidebar أو كتطبيق Google Workspace.

لخطوات التثبيت، بنية الجداول، وضوابط النشر، راجع [دليل Google Sheets وWorkspace](GOOGLE_WORKSPACE_SETUP.md).
